Privacy Policy

Last updated: 2026-10-28

What Trend pipeline accesses

Trend pipeline requests only the Google Drive scope https://www.googleapis.com/auth/drive.file. With this scope it can see and change only the files and folders it created itself. It cannot read any other file in your Google Drive.

What it stores

It uploads daily digest files built from public RSS/Atom feeds (titles, links and short excerpts of public posts) to a folder it creates in the owner's Google Drive. It does not collect personal information about anyone. The OAuth token is stored only on the owner's private server and is not shared.

Sharing

Data is not sold, shared with or transferred to any third party, and is not used for advertising.

Trend pipeline's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can remove Trend pipeline's access at any time at myaccount.google.com/permissions. Files it uploaded stay in your Drive until you delete them.

개인정보처리방침 (요약)

Trend pipeline은 Google Drive의 drive.file 권한만 요청하며, 자기가 만든 파일과 폴더에만 접근합니다. 공개 피드에서 만든 요약 파일만 운영자 본인의 Drive에 올리고, 누구의 개인정보도 수집하지 않습니다. 데이터는 판매하거나 제3자에게 넘기지 않습니다. 접근 권한은 myaccount.google.com/permissions에서 언제든 해제할 수 있습니다.
